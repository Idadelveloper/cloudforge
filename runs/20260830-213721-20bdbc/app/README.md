# personal_notes_api

A small FastAPI service that stores personal notes in DynamoDB.

## Endpoints

| Method | Path              | Description                                        |
| ------ | ----------------- | -------------------------------------------------- |
| GET    | `/health`         | Liveness/readiness probe (checks the notes table)  |
| POST   | `/notes`          | Create a note (`{"title": "...", "body": "..."}`)  |
| GET    | `/notes`          | List notes (`?limit=50&cursor=<opaque>`)           |
| GET    | `/notes/{id}`     | Fetch one note (404 when unknown)                  |
| PUT    | `/notes/{id}`     | Partial update of `title` and/or `body`            |
| DELETE | `/notes/{id}`     | Delete a note (404 when unknown, 204 on success)   |

Note ids are server-generated UUID4 strings; `created_at` / `updated_at` are
ISO-8601 UTC timestamps generated by the service.

## Configuration

| Variable             | Default     | Purpose                                        |
| -------------------- | ----------- | ---------------------------------------------- |
| `NOTES_TABLE_NAME`   | `notes`     | DynamoDB table holding the notes               |
| `AWS_ENDPOINT_URL`   | *(unset)*   | Endpoint override, e.g. `http://localhost:4566` for LocalStack |
| `AWS_DEFAULT_REGION` | `us-east-1` | AWS region                                     |
| `HOST` / `PORT`      | `127.0.0.1` / `8000` | Bind address for the built-in runner  |
| `LOG_LEVEL`          | `INFO`      | Application log level                          |

## Running locally against LocalStack

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

export AWS_ENDPOINT_URL=http://localhost:4566
export AWS_DEFAULT_REGION=us-east-1
export AWS_ACCESS_KEY_ID=test
export AWS_SECRET_ACCESS_KEY=test
export NOTES_TABLE_NAME=notes

uvicorn app:app --host 127.0.0.1 --port 8000
# or: python app.py
```

Interactive docs are served at `http://127.0.0.1:8000/docs`.

## Tests

The test suite is fully offline: it injects an in-memory repository and a fake
DynamoDB table, so no AWS account, credentials or LocalStack instance is needed.

```bash
pip install pytest httpx   # httpx is required by fastapi.testclient
pytest
```

## Layout

- `app.py` — FastAPI routes, request/response handling, error mapping.
- `models.py` — pydantic request/response models.
- `storage.py` — `NotesRepository` interface plus DynamoDB and in-memory backends.
- `tests/test_app.py` — endpoint and storage tests.
